# 05. 5단계 개발 로드맵 명세서 (05_phases_roadmap.md)

숙명여대 IT와 비즈니스혁신 캡스톤디자인 실습 가이드라인에 맞춘 단계별 목표, 구현 기능, 테스트 및 완료 조건입니다.

---

## 🚀 Phase 1: 프로젝트 구성 + 개발 환경
- **구현 목표:** Django 백엔드 프로젝트와 Vue.js 3 프론트엔드 환경 구축, 데이터베이스 연결
- **주요 작업:**
  - Django REST Framework 및 CORS 설정 (`django`, `djangorestframework`, `django-cors-headers`)
  - DB 연결 설정 (PostgreSQL 16 또는 로컬 실습용 SQLite3)
  - Vue 3 + Bootstrap 5 기본 레이아웃 (사이드바 + 메인 화면) 구성
- **완료 조건:** 백엔드 API 서버(`http://localhost:8000`) 및 프론트엔드 개발 서버(`http://localhost:5173`) 정상 구동

---

## 🚀 Phase 2: 로그인 + 기본 관리자 계정
- **구현 목표:** 사번 기반 인증 시스템 구축 및 기본 관리자 계정 자동 생성
- **주요 작업:**
  - `User` 모델 설계 (사번 `employee_id`, 역할 `ADMIN/MANAGER/EMPLOYEE`)
  - 앱 구동 시 `ADMIN` / `admin1234!` 계정 자동 생성 (마이그레이션 or 시그널)
  - `POST /api/auth/login/`, `GET /api/auth/me/` 엔드포인트 구현
  - Vue 프론트엔드 로그인 페이지 및 권한별 사이드바 분기 처리
- **완료 조건:** `ADMIN` 계정으로 로그인 성공 및 역할(`ADMIN`) 표시 확인

---

## 🚀 Phase 3: 팀, 사용자, 평가 항목 관리
- **구현 목표:** 관리자가 조직 및 평가 체계를 등록·관리하는 CRUD 기능
- **주요 작업:**
  - `Team` 및 `EvaluationItem` 모델 생성
  - 관리자용 팀 관리 화면 (팀 등록/수정/삭제)
  - 관리자용 사용자 관리 화면 (사번, 이름, 역할, 소속팀 등록)
  - 관리자용 평가 항목 관리 화면 및 **가중치 합계 100 검증 로직** 구현
- **완료 조건:** 팀, 사용자, 평가 항목이 정상 저장되고, 가중치 총합이 100일 때만 유효하게 처리됨

---

## 🚀 Phase 4: 매니저 평가 입력
- **구현 목표:** 매니저가 소속 팀원에 대해 1~5점 척도로 평가하고 임시저장/제출
- **주요 작업:**
  - `Evaluation`, `EvaluationScore` 모델 생성 (매니저-직원 unique 제약)
  - 매니저 전용 팀원 목록 및 실시간 진행률(Progress Bar) 계산
  - 평가 입력 모달/화면 (항목별 1~5점 라디오 버튼)
  - [임시 저장 (`DRAFT`)] 및 [최종 제출 (`SUBMITTED`)] 로직 구현 (제출 후 수정 차단)
- **완료 조건:** 매니저가 팀원 평가를 임시저장 후 다시 불러올 수 있고, 최종 제출 후에는 수정이 불가능함

---

## 🚀 Phase 5: 점수 계산 + 팀 보너스 + 응답 현황 + CSV 다운로드
- **구현 목표:** 평가 점수 산출 공식 적용, 팀 보너스 반영, 전체 응답 현황 모니터링 및 결과 엑셀 추출
- **주요 작업:**
  - 점수 계산 알고리즘: 각 항목 $\left(\frac{\text{점수}}{5} \times \text{가중치}\right)$ 합산 + 팀 보너스(0~10점)
  - 관리자용 팀 보너스 부여 및 응답 현황 대시보드
  - 직원용 본인 최종 점수 조회 카드 화면
  - 관리자용 평가 결과 CSV 다운로드 API (`GET /api/admin/results/export-csv/`, utf-8-sig)
- **완료 조건:** 개인 평가 점수와 팀 보너스가 정확히 합산되어 직원에게 조회되고, 관리자가 전체 결과를 CSV로 다운로드 가능
