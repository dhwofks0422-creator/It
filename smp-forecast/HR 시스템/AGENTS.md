2# HR 인사평가 시스템 — 바이브 코딩 규칙서 (CLAUDE.md)

숙명여자대학교 IT와 비즈니스혁신 캡스톤디자인 실습 프로젝트입니다.
사용자는 **비전공 학부생**이므로 모든 설명과 주석은 친절하고 알기 쉬운 한국어로 작성합니다.

## 🚫 0. 개발 원칙 (절대 준수)

- **기능 추가 금지:** 명세서(`specs/`)에 정의되지 않은 기능, 페이지, 라이브러리를 임의로 추가하지 않고 **최대한 단순하게** 만듭니다.
- **작업 경로 제한:** 현재 프로젝트 폴더(`HR system/`) 내에서만 작업하며, 외부 경로에 접근하지 않습니다.
- **패키지 설치 및 삭제 확인:** `pip install`, `npm install` 등의 설치나 파일 삭제 시 반드시 사용자에게 사전에 확인을 구합니다.

## 1. 기술 스택

- **Backend:** Python 3.14 + Django 5.x + Django REST Framework (DRF) + django-cors-headers
- **Frontend:** Vue.js 3 (Composition API) + Bootstrap 5 (또는 Tabler CSS)
- **Database:** PostgreSQL 16 (로컬 개발 환경에서는 연결 전까지 SQLite3 호환 구성)

## 2. 핵심 비즈니스 로직 및 규칙

### (1) 역할 및 인증 (사번/비밀번호 기반)
- **로그인:** 사번(`employee_id`)과 비밀번호(`password`)로 로그인.
- **역할(Role):**
  1. **관리자(`ADMIN`):** 시스템 전체 관리. (시작 시 기본 계정 `ADMIN` / `admin1234!` 자동 생성)
  2. **매니저(`MANAGER`):** 자기 팀 소속 직원 평가 입력.
  3. **직원(`EMPLOYEE`):** 본인 최종 평가 결과 조회.

### (2) 평가 및 점수 계산 공식
- **평가 항목:** 관리자가 추가/수정/삭제하며, 활성화된 항목들의 **가중치 합계는 반드시 100**이어야 함.
- **매니저 평가:** 항목당 1~5점 부여. 임시 저장 가능. 제출 후에는 중복 평가 및 수정 불가.
- **점수 계산 규칙:**
  $$\text{개인 평가 점수} = \sum \left( \frac{\text{점수}}{5} \times \text{가중치} \right)$$
  $$\text{최종 점수} = \min(100, \max(0, \text{개인 평가 점수} + \text{팀 보너스}))$$
  - 예: 가중치 50/30/20 항목에 4/5/3점 부여 시 $\rightarrow (4/5 \times 50) + (5/5 \times 30) + (3/5 \times 20) = 40 + 30 + 12 = 82$점.
  - 팀 보너스(0~10점)가 5점이면 최종 점수는 $82 + 5 = 87$점.

### (3) UI/UX 레이아웃
- Bootstrap 5 기반.
- **왼쪽 사이드바 메뉴** + **오른쪽 본문 내용** 레이아웃.
- 로그인한 사용자의 역할에 따라 접근 가능한 메뉴만 노출.

## 3. 5단계 개발 로드맵 (Phases)

- **Phase 1:** 프로젝트 구성 + 개발 환경 (Django 백엔드 & Vue 프론트엔드 기본 구조)
- **Phase 2:** 로그인 + 기본 관리자 계정 자동 생성
- **Phase 3:** 팀, 사용자, 평가 항목 관리 (CRUD, 가중치 100 검증)
- **Phase 4:** 매니저 평가 입력 (1~5점, 임시 저장, 진행률, 제출 후 수정 불가)
- **Phase 5:** 점수 계산 + 팀 보너스(0~10점) + 응답 현황 + CSV 다운로드
