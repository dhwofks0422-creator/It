# 04. UI/UX 레이아웃 명세서 (04_ui_layout.md)

Bootstrap 5 기반의 직관적이고 깔끔한 대시보드 레이아웃 명세입니다.

---

## 1. 전체 구조 (Left Sidebar + Right Content)

```
+--------------------------------------------------------------------------+
|  [로고] 인사평가 시스템          [사용자 정보: 홍길동 (MANAGER)] [로그아웃]  |
+---------------------+----------------------------------------------------+
|  [사이드바 메뉴]    |  [메인 콘텐츠 영역]                                |
|  - 팀 관리          |                                                    |
|  - 사용자 관리      |  - 현재 페이지 제목 및 액션 버튼                   |
|  - 평가 항목 관리   |  - 데이터 테이블, 카드, 폼 입력 화면               |
|  - 평가 현황/결과   |                                                    |
|                     |                                                    |
|  (역할별 동적 메뉴) |                                                    |
+---------------------+----------------------------------------------------+
```

---

## 2. 역할별 사이드바 메뉴

1. **관리자 (`ADMIN`):**
   - 🏢 **팀 관리**: 팀 등록/삭제 및 팀 보너스 점수(0~10) 부여
   - 👥 **사용자 관리**: 사번, 이름, 역할, 팀 지정
   - 📝 **평가 항목 관리**: 평가 항목 및 가중치(합계 100 검증) 관리
   - 📊 **평가 결과 및 현황**: 팀별 응답 현황, 최종 점수 테이블, CSV 다운로드
2. **매니저 (`MANAGER`):**
   - 📋 **팀원 평가**: 소속 팀원 목록, 평가 진행률 바, 1~5점 입력 및 임시저장/제출
3. **직원 (`EMPLOYEE`):**
   - 🏆 **내 평가 결과**: 개인 점수 + 팀 보너스 = 최종 점수 카드 조회

---

## 3. 핵심 UI 컴포넌트

- **로그인 모달/화면:** 사번, 비밀번호 입력 필드와 직관적인 [로그인] 버튼.
- **평가 폼:** 각 평가 항목별 가중치 표기와 1~5점 라디오 버튼/드롭다운, [임시 저장] 및 [최종 제출] 버튼.
- **진행률 바(Progress Bar):** 매니저 평가 화면 상단에 `완료 인원 / 전체 팀원 (%)` 시각화.
- **가중치 총합 배지(Badge):** 평가 항목 관리 화면 상단에 `가중치 합계: 100/100`을 실시간 표시(100 미만/초과 시 빨간색 경고).
