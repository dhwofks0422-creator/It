# 01. 기능 요구사항 명세서 (01_requirements.md)

숙명여자대학교 IT와 비즈니스혁신 캡스톤디자인 HR 인사평가 시스템의 기능 요구사항입니다.
**명세에 없는 기능은 추가하지 않고 최대한 단순하게 만듭니다.**

---

## 1. 공통 기능 (인증 및 접근 제어)
- **로그인 방식:** 사번(`employee_id`)과 비밀번호(`password`) 기반 로그인.
- **사용자 역할 (3가지):**
  - `ADMIN` (관리자)
  - `MANAGER` (매니저/부서장)
  - `EMPLOYEE` (일반 직원)
- **로그아웃:** 현재 세션/토큰 종료 및 로그인 화면 이동.

---

## 2. 역할별 세부 기능

### (1) 관리자 (`ADMIN`)
1. **기본 관리자 계정 자동 생성:**
   - 앱 최초 구동(마이그레이션) 시 `사번: ADMIN`, `비밀번호: admin1234!` 계정을 자동 생성.
2. **팀 관리 (CRUD):**
   - 팀 추가, 목록 조회, 수정, 삭제.
   - 팀 보너스 점수(0~10점) 설정 및 수정.
3. **사용자 관리 (CRUD):**
   - 사용자 등록 (사번, 이름, 비밀번호, 역할, 소속 팀).
   - 목록 조회, 정보 수정, 삭제.
4. **평가 항목 관리 (CRUD):**
   - 평가 항목 추가, 목록 조회, 수정, 삭제.
   - 각 항목은 제목과 가중치(정수)를 가짐.
   - **가중치 검증:** 전체 활성화된 평가 항목들의 가중치 합계는 반드시 **100**이어야 함 (100이 아닐 경우 경고/제출 불가).
5. **응답 현황 조회 및 결과 관리:**
   - 팀별/직원별 평가 진행 상태 (미제출 / 임시저장 / 제출완료) 조회.
   - 팀 보너스 점수 부여 (0~10점 범위).
6. **평가 결과 CSV 다운로드:**
   - 최종 계산된 평가 결과를 엑셀 호환 CSV(`utf-8-sig`) 형식으로 다운로드.
   - 컬럼: 사번, 이름, 소속팀, 매니저, 개인 평가 점수, 팀 보너스, 최종 점수, 제출일시.

---

### (2) 매니저 (`MANAGER`)
1. **소속 팀 직원 평가 대상자 목록 조회:**
   - 로그인한 매니저 본인과 **동일한 팀에 속한 일반 직원(`EMPLOYEE`)만** 목록에 표시.
2. **평가 입력 (1~5점 척도):**
   - 평가 항목별로 1점부터 5점까지 점수 선택/입력.
3. **임시 저장 및 진행률 표시:**
   - 평가 작성 도중 언제든지 임시 저장(`DRAFT`) 가능.
   - 전체 직원 중 몇 명을 평가 완료했는지 실시간 진행률(예: 3/5명, 60%) 표시.
4. **최종 제출 및 수정 불가 (중복 응답 방지):**
   - [최종 제출(`SUBMITTED`)] 버튼을 누르면 해당 직원에 대한 평가는 완료 처리됨.
   - 제출 후에는 점수 수정이 불가능하며 읽기 전용으로 전환됨.

---

### (3) 직원 (`EMPLOYEE`)
1. **본인 최종 점수 조회:**
   - 매니저가 평가를 제출한 경우, 본인의 **개인 평가 점수**, **팀 보너스 점수**, **최종 점수**를 한눈에 카드 형태로 조회.
   - 아직 평가가 제출되지 않은 경우 "평가 진행 중" 안내 표시.

---

## 3. 점수 계산 규칙

1. **개인 평가 점수:**
   $$\text{개인 평가 점수} = \sum_{k=1}^{n} \left( \frac{\text{점수}_k}{5} \times \text{가중치}_k \right)$$
   - *예시:*
     - 항목 1 (가중치 50): 4점 $\rightarrow 4/5 \times 50 = 40$점
     - 항목 2 (가중치 30): 5점 $\rightarrow 5/5 \times 30 = 30$점
     - 항목 3 (가중치 20): 3점 $\rightarrow 3/5 \times 20 = 12$점
     - 개인 평가 점수 = $40 + 30 + 12 = 82$점

2. **최종 점수:**
   $$\text{최종 점수} = \min(100, \max(0, \text{개인 평가 점수} + \text{팀 보너스 점수}))$$
   - 팀 보너스 범위: 0점 ~ 10점
   - *예시:* 개인 점수 82점 + 팀 보너스 5점 = 최종 **87점**
